# Nova – SaaS Landing Page

Nova is a modern and responsive SaaS landing page designed with a clean and professional user interface.

## ✨ Features

- Modern SaaS landing page design
- Responsive layout for desktop, tablet, and mobile
- Responsive navigation
- Hero section with call-to-action buttons
- Features and pricing sections
- Contact form
- Interactive hover effects
- Clean and professional UI

## 🛠️ Technologies

- HTML5
- Tailwind CSS
- JavaScript
